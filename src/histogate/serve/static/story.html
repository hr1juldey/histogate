The story of HistoGate

A project that runs, breaks, and recovers — because a project that only runs looks like a tutorial.

Act one — the run

A ConvNeXt-Tiny backbone learns nine colorectal tissue classes from a hundred thousand expert-annotated patches. On a clean external validation cohort it performs at the level the literature reports for this benchmark. Everything looks perfect. That is the problem — perfect is what memorization looks like too.

Act two — the break

The same model is fed the unnormalized twin of its training set: same hospital, same patients, same labels — only the scanner's raw stain signal, no laboratory normalization. The model collapses. The failure is not noise; it is a systematic dependency on the stain chemistry of one pipeline. A stain-robust model must survive exactly this.

Act three — the wrong fix

The first repair attempt fine-tuned on raw-stain data at the default learning rate. It destroyed the classifier: catastrophic forgetting in a single epoch. A second, gentler fine-tune recovered most of the domain — but still missed the acceptance gate by a whisker, and honest accounting said: not shipped.

Act four — the physics

Instead of more data, the augmentation was rebuilt from the physics of staining. Tissue color is Beer–Lambert absorption by two dyes, so the augmenter perturbs dye concentrations — estimated per image with a two-stain optical-density basis, residuals preserved pixel-exact — rather than shaking RGB channels. Adversarial tests proved the perturbations land exactly on the hematoxylin axis, stay plausible to a blind discriminator, and cover the stain statistics of scanners never seen. Trained on mixed data with this calibrated jitter, the model finally scores higher on raw multi-scanner input than on the clean set: the domain failure didn't just close, it inverted.

Act five — the judgment calls

Two ensembles were built and measured. The voting gain was real — localized precisely on the patches where members disagreed — but one member's domain weakness poisoned the whole, and it was rejected on measurement, not vibes. Out-of-distribution rejection works but sits below the shipping bar, and that is published as an open failure, scoped for the quality-control work now in flight. Every release faces a nine-check gate; the current model passes all but that one, and the page you came from shows the live values.

The lesson: training is not the hard part anymore. Knowing what to do when data, augmentation and expected behavior go wrong is the engineering — the rest is mechanics.
